Pi-hole Speedtest help

Charts use when a speed test started. Point to either chart to see its start and completion times and values. Older measurements without a known start time retain their recorded time. Use Line or Bar to change the chart style. Scroll over a chart or use the zoom buttons to inspect a shorter time range. Drag horizontally to move through a zoomed range.

The y-axis remains fixed while you zoom so changes stay visually comparable. Open Setup to control the table, export CSV data, change capture frequency, or reset history.

Use Run speed test now on the Overview page to start a measurement immediately.
